# PCA_SUB: 次フェーズ戦略文書

## 現状の診断

ここまでの検証で判明した事実を整理する。

### 確認できたこと
- 日米業種間のリードラグ効果は統計的に存在する（OOS Test R/R=1.92）
- 部分空間正則化PCAによるシグナル抽出は、正則化なし・モメンタムに対して一貫して優位
- パラメータロバスト性は高い（Cfull期間・L・λに対して安定）

### 確認できた構造的問題
- **Gross alpha ≒ 年率21-29%に対し、毎日建替のコストが年率50%超** — コスト未控除で見ると「強い戦略」だが、控除後は赤字
- **TOPIX-17 ETFの流動性が機関投資家のポジションサイズに対して1-2桁不足**
- **シグナルの半減期が1-3日** — 長期保持では情報が腐る

### このプロジェクトの本質的な問い
> 「確かに存在するαを、取引コストと流動性制約の下で、いかにして実現可能な収益に変換するか」

以下、この問いに答えるための具体的な作業を優先度順に記す。

---

## 1. シグナルの情報構造を分解する（最優先）

### 問題意識
現在のシグナルは「米国11業種→日本17業種」の28次元空間で一括処理されている。しかし、αの源泉がどこにあるかを理解しないまま改良を試みても、ノイズを増やすだけになる。

### やるべきこと

#### 1.1 ファクタースコアの分解と可視化
3つの主成分（グローバル・国スプレッド・シクリカル/ディフェンシブ）のファクタースコア f_t の時系列を取得し、各ファクターが日本側リターンをどの程度説明するかを分離計測する。

```
f_t = V_U^T z_U,t  →  f_t = [f_global, f_country, f_cycdef]
```

具体的には:
- K=1（グローバルのみ）、K=2（+国スプレッド）、K=3（+シクリカル）の累積リターンを比較して、どのファクターがαの何%を担っているかを定量化する
- 日次のファクタースコアと翌日JP OC returnの相関を時系列で追跡し、ファクターごとの予測力の時変性を把握する

**期待される成果**: 「αの80%は第3主成分（シクリカル/ディフェンシブ）から来ている」等の知見が得られれば、以降の改良の焦点が定まる。

#### 1.2 業種ペアの伝播行列 B_t の分析
伝播行列 B_t = V_J V_U^T のどのセルが大きいかを集計する。これは「どの米国業種がどの日本業種にリードラグを与えるか」の地図である。

- B_t の時間平均と分散を計算
- 安定して大きいセル（＝信頼できる伝播経路）と、時期によって不安定なセルを分離
- 安定セルだけでシグナルを構成した場合の成績を検証

**期待される成果**: 伝播の強い業種ペア（例: XLK→1625.T（電機・精密））を特定し、選択的なトレードで流動性問題を軽減できる可能性。

## 2. コスト構造を根本から変える（高優先）

### 問題意識
パラメータ調整（リバランス頻度・分位点等）によるbreakeven改善は限界がある。コスト構造そのものを変える設計変更が必要。

### やるべきこと

#### 2.1 条件付き取引（Conditional Trading）
毎日シグナルを計算するが、**シグナル強度が閾値を超えた日だけ取引する**。

- シグナルベクトル ||ẑ_J,t+1|| のノルムまたはファクタースコアの絶対値を条件変数とする
- 閾値を変えて、取引日数 vs Gross AR vs Net AR のフロンティアを描く
- 「月に5回しか取引しないが、取引日のGross alpha = 30bp超」のような戦略が存在するか検証

**なぜこれが重要か**: 毎日20bpのコストを払うから赤字になる。シグナルが弱い日を除外できれば、取引日あたりのGross alphaを大幅に引き上げ、コスト比率を反転させられる。

#### 2.2 ポジションの部分更新（Partial Rebalance）
現在は毎日全ポジションを白紙から構築している。代わりに:

- 前日と同じ方向のポジションは維持（コストゼロ）
- 方向が反転した銘柄だけ入れ替え

実装: `new_weights = prev_weights * (1 - α) + ideal_weights * α` のブレンドで、αの最適値をコスト込みで探索する。ターンオーバーが1/3-1/2に減る可能性がある。

#### 2.3 Close-to-Close戦略への変換
論文のopen-to-close（日中戦略）は、寄り成り＋引け成りの往復コストが発生する。代替案:

- **前日引け→当日引け（CC戦略）**: 1日保持でターンオーバーを半減。ただしオーバーナイトリスクを負う
- **前日引け→翌日引け（2日CC）**: ターンオーバーがさらに半減

OC戦略とCC戦略でGross alphaがどう変わるかを比較し、コスト込みでどちらが有利かを判定する。

## 3. 投資対象の再設計（高優先）

### 問題意識
TOPIX-17 ETFの流動性不足が根本的なボトルネック。ETFにこだわる理由はない。

### やるべきこと

#### 3.1 TOPIX先物1本でのヘッジ付き戦略
シグナルの第1主成分（グローバルファクター）はTOPIX全体の方向を予測している。これをTOPIX先物のロング/ショートで取る。

- f_global > 0 ならTOPIX先物ロング、< 0 ならショート
- TOPIX先物は流動性が十分（日次売買代金数兆円）
- 業種選択のαは失われるが、コスト・流動性問題が消滅する

**検証**: K=1のシグナルでTOPIX先物を売買した場合のNet P&Lを計算し、業種分散alphaとの差を定量化する。

#### 3.2 個別株バスケットへの展開
TOPIX-17の各業種ETFの代わりに、各業種の代表的な大型株（時価総額上位3-5銘柄）をバスケットとして使う。

- 例: 1631.T（銀行ETF）の代わりに 8306（三菱UFJ）+ 8316（三井住友FG）+ 8411（みずほFG）
- 大型個別株はETFより遥かに流動性が高い
- 実装: 業種分類マスターを作成し、各業種ETFのシグナルを個別株に分配

#### 3.3 日経225先物のオーバーナイト戦略
リードラグの本質は「米国の情報が翌日の日本に波及する」こと。日本のベータ成分は日経先物の寄り付きでかなり織り込まれる。

- 米国引け後の日経先物夜間取引（16:30-翌6:00）で、シグナルに基づいてポジションを取る
- 日本の日中セッション（9:00-15:00）で手仕舞い
- 先物なので流動性・コスト問題が大幅に軽減

## 4. シグナルの改良（中優先）

### 問題意識
感度分析でK=4-5が有効であることが判明した。論文のK0=3（事前部分空間の次元）が最適とは限らない。

### やるべきこと

#### 4.1 事前部分空間の拡張
v4, v5として以下を検証:

- **金利敏感/非敏感**: 米国の金利変動が日本の金利敏感業種（銀行・不動産）に伝播するか
- **半導体ファクター**: XLK vs 1625.T（電機精密）のリンクは特に強い可能性
- **資源/非資源**: XLE・XLBと1618.T（エネルギー）・1623.T（鉄鋼非鉄）の関係

構築方法: v1-v3のGram-Schmidt直交化を拡張するだけで実装可能。

#### 4.2 非線形拡張の検討
PCAは線形モデルである。しかし:

- 米国市場が大きく下落した日（z_U のノルムが大きい日）の方がリードラグが強い可能性がある
- 局面（リスクオン/オフ）によって伝播行列が変わる可能性

検証: z_Uの大きさで日を2分割し、それぞれのGross alphaを比較する。非線形性が強ければ、regime-switching的な拡張が有効。

#### 4.3 時間軸の拡張
現在は「米国t日→日本t+1日」の1日ラグのみ。しかし:

- 2日ラグ（米国t日→日本t+2日）にも残存効果がある可能性
- 複数ラグのシグナルを重み付け合算してrobust化できる可能性

検証: ラグ1, 2, 3日のシグナルの相関と、各ラグの限界的予測力を計測。

## 5. 統計的検証の強化（中優先）

### 問題意識
現在の検証はsingle-path backtestのみ。これでは結果が偶然である可能性を排除できない。

### やるべきこと

#### 5.1 Bootstrap信頼区間
日次リターン系列をブロックブートストラップ（ブロック長20日程度）でリサンプリングし、AR・R/R・MDDの95%信頼区間を計算する。

- PCA_SUBのR/Rの95%下限が1.0を超えるか？
- PCA_SUBとPCA_PLAINの差のp値は？

#### 5.2 Fama-French回帰の再現
論文のTable 3-4を再現する。日本のFama-Frenchファクターデータ（Kenneth Frenchサイトから取得可能）を用いて:

- α（切片）の統計的有意性（Newey-West t統計量）
- MKT, SMB, HML, WMLへのエクスポージャー
- PCA_SUBのWML係数が負であること（モメンタム追随ではないこと）の確認

#### 5.3 Multiple testing補正
パラメータ感度で多数のバックテストを実行している。最良パラメータの成績をそのまま報告するとlook-ahead biasになる。Harvey-Liu-Zhu (2016) のmultiple testing frameworkを適用して、αの有意性を補正する。

## 6. 実運用インフラ（低優先・ただし将来必須）

上記1-5で実務可能性が確認できた場合に備えて、以下の設計を進める。

#### 6.1 日次シグナル配信パイプライン
- 米国市場クローズ後（日本時間6:00頃）にデータ取得→シグナル計算→通知
- cron + Slack/LINE通知

#### 6.2 執行シミュレーター
- 板データ（SBI証券のCSV等）を使った寄り付き約定シミュレーション
- market impact modelの構築（Kyle's lambda的なアプローチ）

#### 6.3 リアルタイム監視
- シグナル品質（ファクタースコアの分布、異常値検知）
- regime検知（ボラティリティ急変時のシグナル信頼度低下を検知）
