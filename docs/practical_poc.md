# PCA_SUB 実務PoC仕様書

## 戦略概要

米国業種ETFの当日リターンから、翌営業日の日本業種リターンを予測し、個別株バスケットでロング・ショートを構築する日中戦略。シグナル強度が高い日のみ取引することで、取引コストを超えるNet収益を実現する。

### 収益の源泉
米国市場クローズ時点で確定した**シクリカル/ディフェンシブの相対強弱**が、翌営業日の日本市場に遅れて波及する現象（リードラグ効果）を利用する。αの95%がこの単一ファクターに起因する。

## 最終検証結果

### 最終形の戦略構成

| 項目 | 仕様 |
|------|------|
| シグナル | PCA_SUB (K=3, λ=0.9, L=60) |
| 取引フィルタ | シグナル強度 上位10%の日のみ |
| 執行対象 | TOPIX-17各業種の代表大型株（62銘柄） |
| ポートフォリオ | 等ウェイト long/short, q=0.3 |
| コスト前提 | 片道3bp + 短売2bp（大型個別株） |
| 取引頻度 | 月2-3回 |

### OOS検証済みNet成績（個別株バスケット、3bp片道）

| 期間 | Gross AR (%) | Gross R/R | **Net AR (%)** | **Net R/R** | MDD (%) |
|------|-------:|----:|-------:|----:|-------:|
| Full (2015-2025) | 8.12 | 1.84 | **4.78** | **1.11** | 7.31 |
| Train (2015-2019) | 10.60 | 2.24 | **6.84** | **1.48** | — |
| Valid (2020-2022) | 5.45 | 1.30 | **2.17** | **0.53** | — |
| **Test (2023-2025)** | **6.55** | **1.62** | **3.91** | **0.99** | — |

- **Breakeven = 8.6bp片道** — 大型個別株なら余裕のある水準
- Test期間でもNet黒字を維持（R/R=0.99）
- MDD=7.31%（Full期間）と抑制的

### ETF vs 個別株の比較

| 執行方法 | フィルタ | コスト前提 | Net AR (%) | Net R/R | Breakeven |
|---------|---------|-----------|----------:|--------:|----------:|
| ETF（全日取引） | なし | 5bp | -6.05 | -0.57 | 5.3bp |
| ETF（上位10%） | 90pctl | 5bp | +5.01 | +1.19 | — |
| **個別株（上位10%）** | **90pctl** | **3bp** | **+4.78** | **+1.11** | **8.6bp** |

個別株はETFよりGross alphaが低い（ETFとの乖離があるため）が、コスト優位性（3bp vs 5bp）でNet成績は同等以上。Breakeven 8.6bpは大型株で十分に達成可能。

## 執行設計

### タイムライン（日本時間）

```
06:00  米国市場クローズ
06:30  データ取得・シグナル計算（自動化可能）
07:00  シグナル強度判定 → 取引/見送りを決定
09:00  日本市場オープン → 寄り成りで建て
15:00  日本市場クローズ → 引け成りで手仕舞い
```

### 銘柄選定
ETFレベルのシグナルに基づき、以下のルールで銘柄を決定:

1. PCA_SUBシグナルで日本17業種をランキング
2. 上位30%（5業種）をロング、下位30%をショート
3. 各業種の代表大型株（3-5銘柄）に等ウェイト分配
4. 結果として約15-25銘柄のポートフォリオ

### ポジションサイズの目安

| 条件 | 値 |
|------|------|
| 片側グロス | 1,000万円〜5,000万円 |
| 1銘柄あたり | 100万〜500万円 |
| 対売買代金比 | 0.01-0.1%（マーケットインパクト無視可能） |

TOPIX-17 ETFでは1銘柄100万円でも売買代金の3-10%を占めたが、大型個別株では0.01%未満。

## リスク管理

### 想定されるリスクシナリオ

| リスク | 影響 | 対策 |
|--------|------|------|
| シグナル構造の崩壊 | α消失 | 月次でR/R監視、閾値割れで一時停止 |
| 日本市場の寄り付き乖離 | 執行コスト増 | 成行でなくVWAP近似注文 |
| 個別銘柄の異常値 | 1銘柄で大きな損失 | 1銘柄上限を設定、ストップロス |
| 空売り不可 | ショートレグ構築不能 | 貸株確認を前日に実施 |
| 米国市場休場 | シグナルなし | 取引スキップ |

### 監視指標

- 日次: シグナル強度、ファクタースコアの分布
- 週次: 累積P&L、ドローダウン
- 月次: rolling R/R（60日窓）、取引回数、平均P&L per trade

## コスト試算

### 年間コスト（片側5,000万円、月3回取引）

| 項目 | 1回あたり | 年間（36回） |
|------|--------:|----------:|
| 売買手数料 | 〜0 | 〜0 |
| スプレッドコスト（3bp × 1億円） | 30,000円 | 1,080,000円 |
| 短売貸株料（2bp × 5,000万円） | 10,000円 | 360,000円 |
| **コスト合計** | **40,000円** | **1,440,000円** |

### 年間期待収益

| 項目 | 値 |
|------|------|
| 片側グロス | 5,000万円 |
| Net AR | 3.9% (Test期間OOS) |
| **期待年間収益** | **約195万円** |
| **コスト控除後** | **約50万円** |

※ 片側1億円なら期待収益は約390万円 − コスト288万円 = 約100万円

### 収益性の閾値

- **片側5,000万円以上で年間利益50万円超**
- **片側1億円以上で年間利益100万円超**
- 流動性の制約上、**片側5億円が上限**（日次売買代金の1%未満を維持）

## 判断ポイント

### Go条件
- [x] OOSでNet黒字確認済み（Test R/R=0.99）
- [x] Breakeven 8.6bp > 実務コスト 3bp（マージン十分）
- [x] 個別株の流動性は片側5億円まで問題なし
- [ ] 証券会社APIでの自動注文が可能

### No-Go条件
- [ ] rolling R/Rが3ヶ月連続で0.5未満
- [ ] シグナル構造の崩壊（ファクタースコアが0に収束）
- [ ] 空売り規制の変更で短売レグが構築不能
